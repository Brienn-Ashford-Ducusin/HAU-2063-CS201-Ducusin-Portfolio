## Description
This repository contains my personal frontend developer portfolio website. It was built to showcase my technical skills, my educational progress as a Computer Science student at Holy Angel University, and the projects I have completed through the FreeCodeCamp Responsive Web Design coursework. * **HTML5**: Semantic document structure, landmark roles, and accessible forms.
* **CSS3**: Custom properties, responsive units, Flexbox, and CSS Grid.
* **Git & GitHub**: Version control, feature branching, conventional commits, and pull request workflows.
* **VS Code**: Primary source code editor.
